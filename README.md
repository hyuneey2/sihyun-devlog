## 박시현 개발 블로그

프로젝트에서 마주한 문제와 고민, 해결 과정을 기록하는 개인 개발 블로그입니다.

기능 구현 결과뿐 아니라 문제의 원인을 분석하고 해결 방법을 선택한 과정을 중심으로 기록합니다.

### 주요 기능

#### 게시글

* Markdown 기반 게시글 작성 및 조회
* 카테고리와 태그를 활용한 게시글 분류
* 시리즈 게시글 관리
* 게시글별 고유 주소 관리
* 반응형 게시글 목록 및 상세 페이지

#### 게시글 관리

* 새 게시글 작성
* 기존 게시글 수정 및 삭제
* Markdown 미리보기
* 임시 저장 및 발행 상태 관리
* 카테고리, 태그, 게시글 주소 관리

게시글 관리 기능은 인증된 관리자만 사용할 수 있습니다.

#### 데이터 관리

* D1 데이터베이스 기반 게시글 관리
* 기존 Markdown 게시글을 초기 데이터로 활용
* 첫 실행 시 게시글 테이블과 초기 데이터 자동 구성

### 기술 구성

| 구분        | 기술             |
| --------- | -------------- |
| Framework | Vinext         |
| UI        | React          |
| Language  | TypeScript     |
| Styling   | Tailwind CSS 4 |
| Database  | D1             |
| Content   | Markdown       |

### 로컬 실행

#### 1. 저장소 내려받기

```bash
git clone <repository-url>
cd <repository-name>
```

#### 2. 패키지 설치

```bash
npm install
```

#### 3. 환경 변수 설정

```bash
cp .env.example .env.local
```

실행에 필요한 환경 변수는 `.env.example`을 참고해 설정합니다.

관리자 인증 정보와 실제 환경 변수 값은 공개 저장소에 포함하지 않습니다.

#### 4. 개발 서버 실행

```bash
npm run dev
```

개발 서버가 실행되면 브라우저에서 안내된 로컬 주소로 접속합니다.

게시글 테이블과 기존 게시글 데이터는 첫 실행 시 자동으로 준비됩니다.

### 주요 폴더 구조

```text
app/
├── admin/          # 게시글 관리 화면
├── api/admin/      # 게시글 작성·수정·삭제 API
├── about/          # 소개 페이지
└── posts/          # 게시글 목록 및 상세 페이지

components/         # 공통 UI 컴포넌트
content/posts/      # 초기 데이터로 사용할 기존 Markdown 게시글
db/                 # 게시글 데이터베이스 스키마
lib/post-data.ts    # 게시글 조회 및 저장 로직
```

### 게시글 데이터 흐름

```text
기존 Markdown 게시글
        ↓
첫 실행 시 초기 데이터 등록
        ↓
D1 데이터베이스에서 게시글 관리
        ↓
블로그 게시글 목록과 상세 페이지에 반영
```
